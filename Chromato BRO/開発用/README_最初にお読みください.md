# Chromato BRO ver26.10.27

Apple Silicon / macOS 12.3以降向けのオフラインGPC/SEC解析アプリです。ChromeやVS Codeは実行に不要です。

## 起動と画面切替

`/Applications/Chromato BRO.app` をFinderから開きます。成果物は `Chromato BRO.app` と `Chromato BRO Mac ver26.10.27.zip` です。

初期順序は「概形表示 → 分子量計算 → 検量線作成」。ページボタンを約0.45秒長押し、または右ボタンを押してドラッグすると並べ替えできます。Escapeで取消。順序は保存され、再起動時は左端のページを開きます。

## 概形表示

CRM / CSVを複数読み込み、試料ごとに表示・色・凡例名・上下移動量を設定できます。標準表示は全体、横軸と曲線のみ、凡例なし。目盛数字と横軸ラベルの文字サイズは42px、横軸名は `elution time (min)` です。

各試料の全測定範囲を基準に、開始信号を0、最大ピークを100へ独立規格化します。

`Y(t) = 100 × (S(t) − S(t0)) / (Smax − S(t0))`

ズーム時の自動規格化は初期ONです。ONではズーム先の範囲で規格化し直し、OFFでは規格化値を固定します。右ドラッグの横移動では再規格化しません。「この範囲で基準を合わせる」で現在の表示範囲を基準に再計算します。「最大100のピーク範囲を選択」では、基準線と表示範囲を変えずに最大100にするピークを指定できます。基準範囲外の信号は100を超える場合があります。y軸移動量は規格化後に加算します。負値は保持し、分子量計算には影響しません。

始点・終点を結ぶ線を差し引く表示、元信号表示も選べます。線幅・フォント・ラベル位置・グラフ領域の縦横比を調整でき、縦目盛線・横目盛線は点線で個別にON/OFFできます。縦目盛線の間隔はmin、横目盛線は縦軸の信号単位（規格化時は%）です。

PNG保存・画像コピー・規格化CSVはグラフ直下。画像は白背景、標準2400×1400px、縦横比変更時は高さが変わります。コピー形式はPNG/TIFF。CSVは表示範囲内の規格化データです。

## 分子量計算

CRM / CSVを読み込み、積分区間・ベースライン・検量線を設定します。Mn・Mw・Mz・Mpはg/mol、分散度Đは無次元です。結果CSV、分布CSV、PNG、プロジェクトJSONを保存できます。外挿の有無は積分レポートで確認できます。

概形表示と測定データ一覧は共有します。「全て削除」は読み込み済み測定データを一覧から取り除きます。元ファイルと検量線は保持します。

## 検量線作成

ANL（RI / UV）の標準ピーク、標準点CSV、または測定データのピークから検量線を作成します。既知分子量を編集して1〜3次近似を計算し、R²・残差を確認して「この検量線を解析に適用」を押してください。検量線JSONの保存・再読込にも対応します。

ANLの標準試料名・検量線名はファイル名から取得します。新しいANLでは保持時間を更新し、既存の分子量（空欄を含む）を行順で保持します。追加行は空欄、または転記設定がONならファイル内の分子量を使います。異なる標準試料や行の追加・削除後は、対応する分子量を確認してください。初期検量線の値は初回ANLへ自動転記しません。

測定日はANL・標準点CSV・検量線JSONのファイル名から取得します。例：`2026.1001`、`2026-10-01`、`20261001` → `2026/10/01`。これは機器内部の日時を検証したものではありません。日付なしJSONは保存済みメタデータを維持し、日付なしANL/CSVは空欄にします。時刻は推測しません。日付・時刻は必要に応じて訂正できます。積分レポートには測定日時・PSstandard・検出器を表示します。

## 保存とショートカット

⌘O：現在の画面で読込。⌘S：プロジェクト／検量線保存。⌘1：分子量計算、⌘2：検量線作成、⌘3：概形表示（ページ順序を並べ替えても固定）。⌘0：全体表示。Control+⌘F：フルスクリーン。右上のヘルプからオフラインガイドを開けます。

測定データ、検量線、解析条件、編集中の入力、概形設定、ページ順序を自動保存します。終了時は保存完了を待ち、次回はデータを復元して左端ページを開きます。研究記録は別途プロジェクトJSONとして保存してください。

保存先：`~/Library/Application Support/jp.gpcmac.analyzer.native/session-v1.json`。前回分は同じフォルダの `session-v1.previous.json`。上限100MB。破損・未対応・他インスタンスによる変更を検出した場合は上書きを拒否します。復元エラー時は原本をコピーして保管し、バックアップまたはプロジェクトJSONから復元してください。従来の `GPCA-project-v1` / `GPCA-calibration-v2` に対応します。Bundle Identifierは変更していません。

## 解析上の制約

Chromato-PROおよびメーカーの公式製品ではありません。確認できたCRM / ANL形式に対応しています。未知の時間軸・信号スケール・検出器は元ソフト／対応CSVと照合してください。ANLはピーク情報の読込に使用し、波形として扱いません。

通常解析は補正後の正信号を質量濃度に比例すると仮定した相対分子量です。負信号は0にクリップし、時間幅を考慮して積分します。標準物質、検出器、カラム、溶離液、温度に合う検量線を使用してください。初期検量線の適合を保証しません。外挿は標準試料の実測範囲外であり、長文警告を表示しなくても精度上の制約は残ります。未照合CRM・初期検量線使用・非物理的な結果・入力不正の警告は該当時に表示します。

CRM内の検量線名は参考情報で、自動適用しません。Excel互換モードは通常UIにはなく、旧設定も通常解析へ移行します。過去のExcel互換照合値と通常解析の期待値は区別します。

照合済み41.crmの概形だけに対応CSVとの2点（0.4秒）の位置差を調整した表示用配列を使います。解析用配列は変更せず、未知のCRMへ推測適用しません。詳細は [概形検証](analysis/normalization-validation.md) と [CPF301調査](analysis/CPF301-investigation.md) を参照してください。

## 概形の基準合わせ（7.8.2）
比較したいピークを拡大し、「基準の合わせ方」を選んで「この範囲で基準を合わせる」を押します。「開始点を0・最大を100」は開始信号を差し引きます。「両端の基準線で補正・最大を100」は表示範囲の両端の信号を結ぶ線を差し引いてから規格化します。ピークの前後の裾を含む範囲を指定してください。試料ごとに独立して処理し、ズームや表示範囲入力では基準を変えません。元信号と分子量計算には影響しません。

## 概形プロジェクトと凡例（7.8.4）
グラフ下で基準合わせ、プロジェクト保存・読込を操作できます。プロジェクトJSONには全測定データ、重ね合わせ、色、表示範囲、補正基準、凡例名・サイズ・位置を保存します。凡例の表示をオンにし、画像内の凡例をドラッグして位置を調整します。文字サイズと位置は数値入力も可能です。画像保存・コピーにも反映されます。

## 保存した検量線と横軸数字間隔（7.9.0）
分子量計算の「現在の検量線を保存」で名前付き保存し、「保存した検量線」から選んで適用できます。検量線作成で「解析に適用」した検量線も自動で一覧に保持します。係数・測定日・検出器・標準試料を保存し、切替時に再回帰は行いません。同名でも条件が異なるものは別項目として保持します。削除は一覧だけに作用し、適用中の検量線は維持します。保存一覧は再起動・プロジェクト保存に対応し、プロジェクト読込時は既存一覧に統合します。
概形表示と分子量計算で「横軸の数字間隔 [min]」を入力できます。空欄は自動、1以上の整数を指定します。縦点線の間隔とは独立です。表示設定は計算値を変えません。

## ピーク範囲と作成画面での検量線保存（7.9.1）
検量線作成の最下部から、計算済み検量線を保存一覧に追加できます。未適用の検量線も保存でき、解析への適用は別操作です。概形では「最大100のピーク範囲を選択」を押して横にドラッグすると、その範囲の最大ピークを試料別に100にします。表示範囲・ベースラインは変更しません。範囲外の高いピークは100を超える場合があります。「ピーク範囲を自動に戻す」で解除します。範囲はプロジェクトと再起動で復元します。
プロジェクトは概形グラフ下、または分子量計算の「プロジェクトを開く」から読み込みます。線幅・フォント等の調整は概形グラフ直下に配置しています。

## 補助線と画像余白（7.9.2）
概形グラフ下で補助線の太さ（0.5〜20px）と濃さ（0〜100%）を変更できます。縦横の点線に共通適用し、再起動・プロジェクト保存で復元します。PNG保存と画像コピーでは下端の未描画の白い余白を自動調整します。負のピーク・文字・凡例は残し、グラフ領域の縦横比は変更しません。デスクトップ幅では横の設定欄を独立スクロールできます。

## 概形の自動規格化・順序・タイトル（7.10.0）
プロジェクトの保存・読込は概形グラフの下で操作できます。ズーム時の自動規格化は初期ONです。ONではズーム先を基準範囲とピーク範囲に使って再規格化し、OFFでは値を固定します。右ドラッグの横移動では再規格化しません。測定一覧の「並べ替え」をドラッグ、または↑↓で移動すると凡例・曲線の順序が変わります。元データと分子量計算には影響しません。
グラフ内タイトルは文字・フォント・文字サイズ・枠の幅高さ・枠線・位置を設定できます。画像内でドラッグ移動し、右下の角で枠サイズを変更できます。設定はプロジェクト・再起動で復元します。

## 設定欄の配置（7.10.2）
「グラフ内タイトル」以降の設定（線・文字、表示切替、凡例）は左の独立スクロール欄に配置。PNG保存・画像コピー・プロジェクト保存/読込・自動規格化・基準合わせ・補助線はグラフ下にあります。

## タイトルの文字装飾と直接編集（26.10.20）
タイトル欄で文字を選択し、「下付き x₂」「上付き x²」「標準」で指定します。例：CHCl3の3だけを選択して下付きにします。画像内のタイトルをダブルクリックすると直接編集できます。編集欄でも文字を選択して装飾でき、プレビューで確認します。「完了」またはEnterで確定、Escapeで取消、Shift+Enterで改行します。
「枠を文字に合わせる」は文字と装飾の大きさに合わせて余白を詰めます。手動枠の下限は24×24pxです（文字が収まる大きさが必要です）。装飾と枠設定はプロジェクト・再起動後も保持します。
