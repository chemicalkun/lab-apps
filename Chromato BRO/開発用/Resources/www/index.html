Chromato BRO ヘルプ

バージョン 26.10.21 · GPC/SECデータ解析ソフトウェア

はじめに・画面の切り替え

「概形表示」「分子量計算」「検量線作成」を右上のボタンで切り替えます。初期の順序はこの並びです。ボタンを長押し、または右ボタンでドラッグすると並べ替えられます。再起動時は、データと設定を復元して左端の画面を開きます。

概形表示：読み込みと重ね合わせ

「CRM / CSVを読み込む」で複数ファイルを選択できます。一覧で表示・非表示、色、凡例名、y軸移動量を変更します。「並べ替え」のドラッグ、または↑↓で順番を変えると、曲線と凡例の順番にも反映されます。「削除」「全て削除」は一覧から取り除くだけで、元のファイルや検量線は削除しません。

初期表示は全体表示・「横軸と曲線のみ」・凡例なしです。横軸名は elution time (min) です。

規格化と基準の合わせ方

標準の「試料ごとに規格化（最大100）」では、各試料の開始信号を0、最大ピークを100に揃えます。濃度や検出強度が違う試料も個別に規格化します。y軸移動量は規格化後に加算します。これらは表示専用で、元データと分子量計算を変更しません。

  • ピークを指定：「最大100のピーク範囲を選択」を選んでグラフを横にドラッグするか、グラフ下の「最大100のピーク範囲 [min]」へ入力します。各試料の指定範囲内の最大ピークが100になります。基準線と表示範囲は変わりません。範囲外の高いピークは100を超えることがあります。
  • 表示範囲を基準にする：グラフ下で「開始点を0・最大を100」または「両端の基準線で補正・最大を100」を選び、「この範囲で基準を合わせる」を押します。
  • ズーム時の自動規格化：初期ONです。ONではズーム先の範囲で規格化し直します。OFFでは規格化値を固定して表示範囲だけを変えます。右ドラッグによる横移動では再規格化しません。

「概形表示方法」から、始点・終点の基準線補正や元信号表示へ切り替えられます。開始信号より小さい値は負になります。必要に応じて比較範囲で基準を合わせるか、両端の基準線による補正を選んでください。負の値は内部データに保持します。基準線補正の始点・終点は、分子量計算とは独立して設定できます。

グラフの拡大・移動

「枠でズーム」を選び、左ドラッグで囲んだ範囲を拡大します。ピンチで拡大・縮小、右ボタンを押したままドラッグすると横移動できます。「全体表示」またはダブルクリックで全体へ戻します。表示開始・終了、縦軸の最小・最大値も数値入力できます。範囲選択を取り消すにはEscapeを押します。

タイトル・凡例・図のスタイル

左欄でタイトル、線幅、フォント、目盛り数字と横軸ラベルのサイズ、凡例などを変更できます。左欄はグラフと独立してスクロールします。横軸の数字間隔は空欄で自動、1以上の整数で指定します。数字と軸ラベルの標準サイズは42pxです。文字サイズ・線幅の数値は出力画像を基準とします。

画像内のタイトルはダブルクリックで直接編集できます。文字を選び「下付き」「上付き」で CHCl₃ などを表現します。Enterまたは「完了」で確定、Shift＋Enterで改行、Escapeで取り消します。タイトルをドラッグすると移動、右下の角で枠サイズを変更できます。「枠を文字に合わせる」や「枠を合わせる」で余白を調整します。

「ファイル名の凡例を表示」をONにすると凡例が画像内に表示されます。凡例名は測定一覧で編集でき、文字サイズ・位置は左欄で変更、画像内ではドラッグで移動できます。

グラフ下では縦目盛線・横目盛線を個別にON/OFFできます。どちらも点線です。縦の間隔はmin、横の間隔は縦軸の単位（規格化時は%）で指定します。太さ・濃さは両方向に共通です。「グラフ領域の横：縦」で縦横比を変更できます。

画像・プロジェクトの保存と読み込み

概形グラフの下に「PNG保存」「画像をコピー」「プロジェクト保存」「プロジェクトを開く」があります。画像は現在の表示・タイトル・凡例・補助線を反映した白背景です。コピー後は貼り付け先で⌘Vを押します。規格化時は「規格化CSV」も出力できます。

プロジェクトJSONには測定データ、重ね合わせ、色、順番、基準範囲、タイトルの文字装飾、凡例などを保存します。「プロジェクトを開く」で復元できます。分子量計算の保存欄にも同じプロジェクト操作があります。自動保存とは別に、研究記録としてプロジェクトを保存してください。

分子量計算

CRM / CSVを読み込み、積分範囲とベースライン、適用検量線を設定します。「積分範囲を選択」「ベースライン範囲を選択」を選んでドラッグするか、時刻を入力します。ベースラインは積分範囲の両端を結ぶ方法、独立した始点・終点を結ぶ方法、傾き・切片の入力、0基準から選べます。

Mn・Mw・Mz・Mpはg/mol、分散度ĐはMw / Mnです。積分レポートで積分区間、ベースライン、適用したPSstandard検量線の測定日時・検出器、外挿の有無を確認できます。結果CSV、分布CSV、PNG、プロジェクトJSONを保存し、印刷 / PDF保存も利用できます。

検量線作成・保存・適用

ANLのRI / UVを選び、標準試料の10ピークの保持時間を読み込みます。標準試料名・検量線名・測定日はファイル名から取得します。時刻は推測しません。新しいANLへ読み替えても入力済み分子量は行順で保持するため、各ピークとの対応を確認してください。

各行の既知分子量を編集し、「使用」で近似に含める点を選択します。行の追加・削除、標準点CSV、測定データのピーク取り込みにも対応します。1〜3次の「検量線を計算」で係数・R²・RMSE・残差を確認し、「この検量線を解析に適用」で反映します。計算・保存だけでは解析の検量線は変わりません。

分子量計算の「現在の検量線を保存」、検量線作成ページ最下部の保存操作で、複数の検量線を保持できます。分子量計算の「保存した検量線」から選択して適用します。検量線JSONはファイルへの保存と再読み込みにも対応します。

自動保存とショートカット

測定データ・適用検量線・編集途中の標準試料・表示設定・ページ順序を自動保存します。終了時に保存を待ち、再起動後も復元します。復元や保存のエラー時は原本を上書きしません。元の測定ファイルを変更することもありません。

⌘O：現在の画面で読み込み、⌘S：プロジェクト／検量線保存、⌘1：分子量計算、⌘2：検量線作成、⌘3：概形表示、⌘0：全体表示。これらの画面番号はボタンを並べ替えても固定です。

自動保存先：~/Library/Application Support/jp.gpcmac.analyzer.native/session-v1.json。前回分は session-v1.previous.json です。

最新版へのアップデート

更新先はアプリに組み込み済みで、URLの入力・変更は不要です。メニューバーの「アップデートを確認…」を選び、新版があればダウンロードして「更新して再起動」を実行します。Macは「Chromato BRO」メニュー、Windowsは「ヘルプ」メニューにあります。データ・検量線・設定は引き継がれます。

Macはアプリケーションフォルダへ移動して起動してください。WindowsはZIPを「すべて展開」し、フォルダ全体を保管して中のEXEを起動します。EXEだけを取り出さないでください。更新時はアプリ保存先への書き込み権限が必要です。

対応形式と解析上の制約

CRM・ANLは確認できたChromato-PRO形式に対応します。未知の形式、チャンネル、時間軸、信号スケールは元ソフト／対応CSVと照合してください。Chromato-PROおよびメーカーの公式製品ではありません。ANLはピーク情報を読み込む形式で、クロマトグラムの波形は表示しません。CSVは保持時間（min）と信号を読み込み、Rt / Concヘッダーにも対応します。

通常解析は正の補正信号を質量濃度に比例すると仮定した相対分子量です。負信号を0にクリップし、時間幅を考慮して積分します。標準物質、検出器、カラム、溶離液、温度の違いは自動補正されません。初期検量線は測定条件への適合を保証しません。外挿の有無は積分レポートで確認できます。測定条件に合う検量線を適用し、計算不能や非物理的な結果の警告を確認してください。

解析は端末内で完結し、オフラインで使用できます。インターネット接続はアップデートの確認・ダウンロード時に使用します。
