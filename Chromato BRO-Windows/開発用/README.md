# Chromato BRO — Windows版 26.10.29

Windows 11 / Intel・AMD（x64）用です。Mac完成版26.10.27を元にした独立プロジェクトです。
配布版 26.10.27（Release）。Windows実機での起動・操作確認は未実施です。確認済みの内容と未確認事項は末尾に記載しています。

## 起動

1. `Chromato BRO Windows ver26.10.27.zip` をWindowsへコピーします。
2. 右クリック →「すべて展開」で、フォルダ全体を展開します。
3. 中の `Chromato BRO.exe` をダブルクリックします。

.exeだけを取り出さず、DLLとwwwフォルダを同じ場所に置いてください。任意のユーザーフォルダから起動できます。Chrome・VS Code・.NET SDKのインストールは不要です。.NET実行環境は同梱しています。

Microsoft Edge WebView2 Runtimeを使用します。Windows 11には通常含まれていますが、削除・破損している場合はMicrosoft公式配布元から導入してください。ブラウザのEdgeを起動する必要はありません。
https://developer.microsoft.com/microsoft-edge/webview2/

このビルドにはコード署名がありません。ダウンロード時にWindowsの警告が出る場合があります。システム全体のセキュリティ設定を変更する必要はありません。

## 画面とデータ

- **概形表示**：CRM / CSV読込、試料別の独立規格化、重ね合わせ、色・凡例・上下移動、枠ズーム・ピンチ、右ドラッグ横移動、縦横点線、PNG保存・画像コピー・規格化CSV。
- **分子量計算**：積分・ベースライン設定、Mn・Mw・Mz・Mp・Đ、CSV / JSON / PNG、プロジェクト保存・再読込。
- **検量線作成**：RI / UVのANL、標準試料の分子量入力、1〜3次近似、検量線の保存・適用。

解析エンジンはMac版26.10.20と同一です。ANLの再読込時は行順で既知分子量を保持します。測定日はファイル名から取得します。ズーム時の自動規格化は初期ONです。OFFでは基準値を固定し、右ドラッグの横移動では再規格化しません。異なる比較区間に揃える場合は「この範囲で基準を合わせる」を押します。

ページを長押し／右ドラッグで並べ替えできます。起動時は左端ページを表示し、測定データ・検量線・設定は保持します。「全て削除」は一覧のみを空にし、元の測定ファイルを削除しません。

Mac版からの移行は「プロジェクト保存」で出力したJSONをWindows版で読み込んでください。Macの保存フォルダを自動で共有しません。日本語名・空白を含むパスに対応する実装です（Windows実機確認待ち）。

## キーボード

Ctrl+O：現在の画面で開く。Ctrl+S：プロジェクト／検量線保存。
Ctrl+1：分子量計算、Ctrl+2：検量線作成、Ctrl+3：概形表示、Ctrl+0：全体表示。F1：ヘルプ。

## 自動保存

`%LOCALAPPDATA%\GPCAnalyzer\session-v1.json`
前回分は同じフォルダの `session-v1.previous.json`。WebView2の実行キャッシュは `WebView2` サブフォルダです。

終了時に保存完了を待ちます。破損や外部変更を検出した場合は上書きせず、別名プロジェクト保存を案内します。既存データを守るため、同じWindowsユーザーでは同時起動を1つに制限しています。研究記録は別途JSONで保存してください。

## 解析上の制約

CRM / ANLは確認済みのChromato-PRO形式に対応し、メーカー公式製品ではありません。検量線は測定条件に合うものを適用してください。通常計算は正の補正信号を用いた相対分子量です。外挿判定は積分レポートで確認できます。過去のExcel互換照合値を通常解析値と混同しないでください。

## 再ビルド

.NET 10 SDKを導入したWindowsで `build-windows.ps1` を実行します。初回はNuGetから依存パッケージを取得するためネット接続が必要です。ビルド後の解析機能はローカル資源を使用します。

```powershell
dotnet publish src/GPCAnalyzer.csproj -c Release -r win-x64 --self-contained true -o "build/Chromato BRO Windows"
```

WebView2 SDKは1.0.4258.31に固定。Macでクロスビルドする場合も同じコマンドを使用できます。Windows版ソースとMac完成版は別フォルダです。

## 概形表示の保存と凡例
Mac版26.10.20と同じ画面です。グラフ直下で基準合わせ（開始点0、または両端直線補正後に最大100）を実行できます。凡例の表示をオンにすると画像内に描画され、ドラッグで移動し、文字サイズを変更できます。概形の「プロジェクト保存／読込」で、測定データ・重ね合わせ・色・上下移動・補正基準・凡例設定をまとめて保存／復元できます。ズーム時の自動規格化をOFFにすると補正値を固定できます。

## 検量線の保存と横軸数字間隔（2026-10-20）
検量線を名前付きで複数保存し、一覧で選んで解析に適用。係数と標準試料・測定日・検出器を保持し、再起動とプロジェクト保存に対応。プロジェクト読込時は既存一覧へ統合。検量線作成で解析に適用したものも自動保存。横軸数字の間隔は概形と解析で独立して指定（空欄＝自動、1以上の整数）。目盛線間隔とは独立。
MacのWKWebViewで切替時の係数・計算値、再起動後の保持、描画・プロジェクト復元を検証。Windows実機の操作は未検証。
