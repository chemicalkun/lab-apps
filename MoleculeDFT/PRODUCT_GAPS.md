# Gaussian / ChemDrawとの差分と改善順序

確認日：2026-10-14。対象はMolecule DFT 2.9、Gaussian 16 / GaussView 6、ChemDraw。手元のChemDrawは25.5.0.6237。Gaussian本体はこのMacで見つかっていないため、Gaussianとの同条件の数値・速度比較は実施していない。ChemDrawの機能は版・契約・OSによって異なる。

## 今回修正したこと

| 項目 | 従来の不足 | 2.3〜2.5での変更 |
| --- | --- | --- |
| ツールの配置 | 五員環・テンプレートが別の段にあり探しにくい | 芳香環ボタンの横に移動 |
| 構造の配置 | クリック直後に確定し、向きを決めにくい | 環・テンプレートを押したまま回転、離して確定。確定前は構造を変更しない |
| 原子上への配置 | 環ツール間で共有原子と外付け結合が不統一。回転中の基準座標更新で環が変形する | 環は原子1個を共有して外側へ配置。原子団は指定の根元を単結合で接続。接続点を固定して回転し、結合長と次数を保持 |
| 縮合環・連続配置 | 原子1個の共有のみ。配置後に結合ツールへ戻り、方向線が結合と紛らわしい | 近づけた辺・既存結合上で2原子と1結合を共有。別々の環の選択移動でも統合。原子団の根元を固定して回転、選択ツールを維持。補助線を削除しカーソル付近の小さな角度表示に変更 |
| 角度の確認 | 配置角度が分からない | 角度表示、水平・垂直のガイドと5°以内のスナップ。Shiftで15°刻み、Optionで軸スナップ解除 |
| 取り消し | 配置途中の中止が分かりにくい | Escape / pointer cancelで破棄。配置全体を1回のUndoで戻せる |
| 表示移動 | Space・中央ボタンの操作を知らないと使いにくい | 「移動」ツール、Gキー、右ドラッグを追加。分子座標を変えずに移動 |
| 基底依存性の確認 | 3基底のみで、拡散関数・原子価三重ゼータが選べない | 6-31G(d)、6-31+G(d)、def2-TZVPを追加。計算前チェック・実計算・個別ヘルプに対応 |

2.2で修正した範囲選択・グループ移動と、選択部分から繰り返し単位を作る操作は維持する。追加基底はPySCFの定義を使い、球面調和関数を使用する。他ソフトと比較する際は5D / 6D、ECP、構造、汎関数の実装までそろえる。[PySCF基底・ECPの公式説明](https://pyscf.org/user/gto.html)

## 残っている差分

P0は結果の解釈・データ保持に関わるもの、P1は日常作業の機能、P2は用途の拡大。優先順位はこのアプリを有限高分子鎖の計算に使う目的に基づく。

| 優先 | 比較対象・項目 | 現在のMolecule DFT | 次の実装と受け入れ条件 |
| --- | --- | --- | --- |
| P0 | Gaussian：振動解析・熱化学 | 2.8で閉殻2〜50原子（Iを除く）の最適化＋振動解析、虚振動確認、ZPEを実装。自由エネルギー・IR強度・アニメーションは未実装 | 同一計算条件でHessianを求め、並進・回転を除いたモードを検証。水の3モードと虚振動を持つ例で確認してから極小判定を提供 |
| P0 | Gaussian：溶媒・非共有結合の扱い | 2.9でIEF-PCMとD3(BJ)二体補正を実装。D4・非静電溶媒和項は未実装 | 溶媒モデルと分散補正を独立した明示設定にし、エネルギー・勾配・最適化・再現用入力まで整合させる |
| P0 | ChemDraw：化学情報の保持 | 読み込んだMOLの情報は保持するが、化学編集時には元データを破棄。くさび以外のE/Z・同位体・ラジカルの編集往復に制約 | グラフに必要な属性を持たせ、MOL / SMILES → 編集 → 保存 → 再読込で保持する。鏡映・結合変更の立体化学も個別に検証 |
| P1 | ChemDraw：結合・融合、複雑な環 | 原子1個の共有、2原子・1結合の共有による縮合環、別々の環の選択移動による統合、原子団の連続配置に対応。任意の部分構造の原子統合、自由な投げ縄選択は未実装 | 任意の部分選択や立体配置付き構造へ拡張する際に、外部結合・原子価・立体配置の保存とUndoを検証 |
| P1 | ChemDraw：反応式・注釈・図版 | 単一分子の構造図が中心。反応矢印、条件、自由テキスト、図版の整列・寸法設定は未実装 | 化学グラフと図版オブジェクトを分離し、注釈が計算対象に混ざらない保存・出力形式を用意 |
| P1 | ChemDraw：構造データの交換 | MOL / SDF読込、MOL・SMILES貼付、独自プロジェクトに対応。CDX / CDXML・HELM・InChIは未対応 | 対応範囲を明示したインポートから始め、未対応オブジェクトを黙って落とさない。往復検証用ファイルを整備 |
| P1 | Gaussian：計算法と電子状態 | HF、B3LYP、PBE、PBE0のみ。TD、ONIOM、多参照法などは未実装 | 利用目的ごとに追加。エネルギーだけでなく軌道・密度・勾配・表示の意味を検証し、計算法名だけ増やさない |
| P1 | GaussView：座標の制約 | 通常の自由最適化のみ。原子固定、結合長・角度・二面角のスキャンは未実装 | 対象原子の可視指定と入力保存を実装し、固定値と実際の最終座標を照合 |
| P1 | 計算の継続・監査 | 入力・結果・ログ・キューの復旧はあるが、SCFや最適化途中からのチェックポイント再開はない | 計算条件・ライブラリ版・構造の一致を確認して再開。異常終了からの復帰試験を追加 |
| P2 | 高分子の表現 | 有限鎖、プリセット、末端、限定的な共重合体・立体規則性に対応 | 分岐・架橋・一般的な繰り返し括弧・生体高分子表記を分けて設計。表記から計算対象を一意に決める |
| P2 | Gaussian：大きな計算の実行環境 | このMacのCPU、量子計算600原子・1200基底関数の上限 | リモートジョブと資源見積もりを整備。GPU対応は使用エンジン・対応手法・ハードウェア条件を確認して別途実装 |
| P1 | 製品としての品質 | このMacでの検証とローカル署名。正式配布・別Mac・長時間運用の検証は未完了 | Developer ID署名、公証、別環境の初回起動、保存失敗・異常終了・更新の試験を完了 |

Gaussianの振動解析では最適化条件とHessianの条件をそろえる必要があり、収束した構造を表示するだけでは極小の確認にならない。[Gaussian：Vibrational Analysis](https://gaussian.com/wp-content/uploads/dl/vib.pdf)、[Thermochemistry](https://gaussian.com/wp-content/uploads/dl/thermo.pdf)

GaussianのHF / DFT、励起状態、ONIOM、SCRFやGPU・並列実行は公式資料で確認した。ここでは利用可能な機能の差を比較し、速度や精度の順位は付けていない。[Gaussian 16公式資料](https://gaussian.com/g16/gpus.pdf)。原子固定・内部座標設定はGaussViewの説明を参照。[GaussView 6 Help](https://gaussian.com/wp-content/uploads/dl/gv6.pdf)

ChemDraw側はリング・結合、構造の結合とマージ、テンプレート、汎用構造・繰り返し単位、立体化学、図版・データ交換などの製品別機能表を参照した。すべての機能がすべてのエディションに含まれるという比較ではない。[Revvity公式機能表](https://revvitysignals.com/sites/default/files/2025-06/Full%20Dot%20Chart%20ChemDraw%20Suite%20of%20Products.pdf)

## 実装の進め方

直近は「化学情報を落とさない編集」と「最適化した構造の振動解析」を優先する。高分子の折り畳み・配座差を定量評価する用途では、分散補正と溶媒も並行して設計する。2.9では溶媒・分散補正を明示設定で追加した。比較・受け入れ試験を満たした機能だけを通常の計算画面に追加する。

## 2.7時点の推奨追加順

今回の原子ホバーと描画・結果の境界調整は実装済み。以下は未実装であり、提案です。

1. 振動解析：最適化後の虚振動確認、振動モード表示、ZPE・熱化学。
2. 溶媒モデルと分散補正：高分子鎖の配座比較に必要な相互作用の扱いを拡充。
3. 原子固定・結合長・二面角スキャン：鎖の回転障壁や配座依存性を調べる。
4. チェックポイント再開：長時間計算を中断点から続ける。
5. TD-DFT：共役高分子の励起エネルギー・吸収の評価。現在のHOMO–LUMO差とは区別する。

順位はこのアプリの高分子用途に基づく判断です。Gaussianとの数値精度・速度比較は行っていません。公式資料の振動解析と機能一覧を再確認：[振動解析](https://gaussian.com/wp-content/uploads/dl/vib.pdf)、[Gaussian 16機能資料](https://gaussian.com/g16/gpus.pdf)。

2.8: 振動解析の第一段階を実装。PySCFの解析的Hessianと並進・回転を除去した調和振動を使用。水のHF/B3LYP、線形・非線形分子のモード数、負曲率の虚振動を検証。溶媒・分散補正は2.9で追加。座標制約とチェックポイント再開は今後の対象です。

## 2.9 の追加

IEF-PCM、D3(BJ)二体補正、自作モノマーライブラリ、左右の末端指定を実装。PCMには非静電項がなく、Gaussianとの数値比較は未実施。拘束最適化・計算再開・IR強度・熱化学は引き続き未対応です。
