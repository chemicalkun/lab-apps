## 起動

`build/Molecule DFT.app` をダブルクリックします。

Apple Silicon の Mac、macOS 14 以降が対象です。配布用 `.app` には Python と計算ライブラリを同梱しているため、起動時の追加インストールは不要です。計算はこの Mac の CPU で実行され、分子データを外部に送信しません。

## 基本の使い方

1. 構造編集画面で原子と結合を配置します。SMILES から分子を取り込むこともできます。
2. 3D 構造を生成し、分子式、電荷、構造を確認します。省略された水素は RDKit の原子価に従って補います。
3. 汎関数、基底関数、計算の種類、全電荷、スピン多重度を指定します。
4. 計算を開始します。進行状況はログに表示されます。
5. 結果の収束状態、全エネルギー、軌道エネルギー、双極子を確認します。

最初は水（SMILES: `O`）などの小分子の一点計算で動作を確認してください。中性の水は全電荷 `0`、スピン多重度 `1` です。小さい基底関数は試運転に使いやすい一方、研究用途での精度は別途検証が必要です。

結合ツールは **B**、選択・移動は **V**、消去は **E** です。結合ツールで空白をドラッグすると炭素同士の結合を描けます。元素ボタンを選んで原子をクリックすると元素を変更できます。**1 / 2 / 3** は結合次数、**⌘Z** は取り消しです。

右上の「書き出し」で、プロジェクト JSON、MOL 構造式、XYZ 座標、計算結果 JSON を保存できます。プロジェクト JSON は構造・条件・結果をまとめて保存し、再度開けます。自動保存は直近の作業、最大8件の画面履歴と最大30件のジョブを保持します。残しておきたい結果はファイルにも書き出してください。

## PEを描いて計算する

1. 左側の「高分子の鎖を作る」を開き、PE / ポリエチレンを選びます。
2. 重合度nを指定します。`H–(CH₂–CH₂)ₙ–H`の水素終端した有限鎖を生成します。n=5はC₁₀H₂₂、32原子です。
3. 「鎖を生成」で結合を展開します。帯にn・終端・水素込みの原子数を表示します。「重合度を変更」で元の単位から作り直せます。
4. 計算法でDFTまたはHFを選び、エネルギー計算または構造最適化を実行します。まずn=2〜5とSTO-3Gで動作を確認してください。

描いた構造を単位にする場合は、ダイアログ内の番号付き原子から接続点A・Bを選びます。各単位のBを次の単位のAに単結合でつなぎ、その位置の水素を置き換えます。反応機構や縮合時の脱離基の自動推定はしません。立体配置を明示した接続点は、配置を誤って変えないよう拒否します。

nは1〜100です。ただし原子数・基底関数数の上限は別に適用します。PEのn=100は602原子なので描画のみで、現在の計算上限600原子を超えます。上限未満でも長い鎖のHF/DFTは時間がかかります。表示可能な最大nを、実用的に短時間で計算できるnとみなさないでください。

このモデルは**有限鎖の1配座**です。無限鎖、結晶、融体、分子量分布、配座平均を計算しているわけではありません。鎖長・末端・配座への依存性を比較して解釈してください。モデル情報はプロジェクトと結果JSONに保存します。通常のMOL/XYZは繰り返し情報の専用保存形式ではありません。原子や結合を直接編集すると、元の繰り返し情報を解除して通常の分子に戻ります。

## MO法について

HF（Hartree–Fock）は波動関数に基づく分子軌道法です。閉殻にはRHF、開殻にはUHFを用い、電子相関は含めません。HFもDFTも分子軌道を求めますが、交換・相関の扱いが異なり、HFが単純な上位版や高速版という関係ではありません。[PySCF公式SCF説明](https://pyscf.org/user/scf.html)

## 計算の意味

- **一点計算**：RDKit が生成した 3D 構造を固定して、電子状態を計算します。DFT による構造最適化は行いません。
- **構造最適化**：PySCF のエネルギー・勾配と geomeTRIC を使い、原子の 3D 座標を更新します。SCF の収束と構造最適化の収束は別の条件です。
- **全電荷**：分子全体の電荷です。カチオンは正、アニオンは負の値です。
- **スピン多重度**：`2S + 1` です。PySCF へは `spin = 多重度 − 1` として渡します。電子数と両立しない設定は計算前に拒否します。DFTの閉殻一重項は RKS、他のスピン状態は UKS。HFではそれぞれRHFとUHFで計算します。
- **全エネルギー**：核間反発を含む PySCF の全エネルギーで、単位は Hartree（Eh）です。熱補正を含む自由エネルギーではありません。
- **HOMO–LUMO ギャップ**：DFTではKohn–Sham軌道、HFではHartree–Fock分子軌道のエネルギー差です。吸収スペクトルの励起エネルギーや光学ギャップとは異なります。
- **双極子モーメント**：単位は Debye です。荷電分子の双極子は座標原点に依存します。

RDKit の 3D 生成では水素を明示的に追加し、ETKDG による配座生成を行います。通常の3D生成は1配座です。2.0の「配座を探索」では複数候補を比較できますが、全配座を網羅する探索ではありません。[RDKit の説明](https://rdkit.org/docs/GettingStartedInPython.html)

DFT の種類・汎関数の扱いは [PySCF の DFT ドキュメント](https://pyscf.org/user/dft.html)、電荷とスピンは [分子定義の説明](https://pyscf.org/user/gto.html)、構造最適化は [PySCF の最適化ドキュメント](https://pyscf.org/user/geomopt.html)を参照してください。

## 現在の範囲

小分子の気相・基底状態計算を対象にした初期版です。計算時間とメモリ使用量は、原子数だけでなく基底関数の数や収束の難しさによって増えます。

- 対応元素は H、B、C、N、O、F、Si、P、S、Cl、Br、I。鎖の生成は水素込み2,000原子まで、3D生成と量子化学計算は600原子まで、量子化学計算の基底関数数は1,200個までの、1つにつながった分子に対応します。基底関数によっては対象元素を扱えない場合があり、その場合はエラーを表示します。
- 計算法はDFT（B3LYP、PBE、PBE0）およびHF（RHF/UHF）、基底関数は STO-3G、6-31G、6-31G(d)、6-31+G(d)、def2-SVP、def2-TZVP です。I のdef2系にはECPを適用します。DFTには任意でD3(BJ)二体補正を付加できます。
- 振動数・ZPEとIEF-PCM溶媒モデルに対応。エントロピー・自由エネルギーの熱化学補正、TDDFT、周期境界条件は提供していません。
- 構造最適化の収束だけでは、その構造が極小点であることや最安定配座であることは確認できません。極小点の確認には振動数計算などが必要です。
- 汎関数・基底関数・電荷・スピン状態・初期配座の選択で結果は変わります。単純な設定ですべての系を同じ精度で扱えるわけではありません。
- ChemDraw の `.cdx` / `.cdxml`、反応式、文書レイアウトなどの完全な互換機能はありません。くさび／破線の描画には対応しています。
- SMILES / MOL の原本情報は化学的な編集まで保持します。編集後は現在の描画のくさび／破線から立体配置を解釈するので、構造チェックで再確認してください。元ファイルだけにある同位体・ラジカル・E/Z情報を編集後も完全保持する機能ではありません。必要なら指定済みSMILES / MOLを再読み込みしてください。未指定の立体配置には注意を表示します。

ソースコードと計算条件を確認できるように、このフォルダに UI、ネイティブホスト、計算エンジンを分けて保存しています。

| PVA | CH₂–CH(OH) | H / H |
| PTFE | CF₂–CF₂ | H / H |

PEGはHO–(CH₂CH₂O)ₙ–Hで、分子式はC₂ₙH₄ₙ₊₂Oₙ₊₁です。n=1はエチレングリコールです。PTFEなどのH終端は計算用モデルで、工業製品の末端基を再現するとは限りません。ビニル系の単位はhead-to-tailで接続します。PP・PS・PMMA・PVC・PAN・PVAの既定の立体規則性は未指定です。生成した単一配座をアタクチックの統計的モデルなどとは扱えません。2.0では下記の詳細設定で配置を指定できます。

すべて既存のHF（分子軌道法）およびB3LYP・PBE・PBE0で計算できます。まずn=1〜3で試してください。これは有限分子の計算であり、周期境界・結晶・融体の計算ではありません。

構造の参考：[Purdue University — Types of Polymers](https://chemed.chem.purdue.edu/genchem/topicreview/bp/1polymer/types.html)、[PEGを含むポリエーテルの一次研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6599002/)。

## 2.0: 描画から比較まで

### 構造を描く

- 選択ツールで空白からドラッグして範囲を囲み、まとめて移動・削除できます。Shiftクリックで選択を追加。⌘Aで全選択、⌘C／⌘X／⌘Vで構造をコピー・切り取り・貼り付け。
- 「鎖」またはLで、ドラッグの長さに応じたジグザグの炭素鎖を描きます。結合ツールでは接続候補を強調表示します。
- 「自動整形」でRDKitによる2D配置に整えます。ベンゼン、五員環、六員環、エステル、アミド、カルボキシ、ニトリル、メトキシ、ヒドロキシ、アミノのテンプレートを選んで配置できます。原子上なら単結合で接続します。
- 原子上で元素をタイプ、またはダブルクリックして変更。Cl、Br、Siなどの2文字も入力できます。
- くさび・破線の細い側が中心原子です。同じツールで結合を再度クリックすると向きを反転。「構造チェック」でR/Sを確認してください。赤い点線は結合過多の目安で、詳細検証は計算前チェックを使用します。
- コピーした別断片は、計算前に結合して1つの分子にしてください。複数分子の錯体計算は未対応です。

Ketcherは導入候補として検討しましたが、本版は既存のオフラインSVGエディタを拡張しています。Ketcherを同梱した製品ではありません。

### 高分子を設定する

「高分子の鎖を作る」の末端構造で左右の末端を指定します。詳細設定では立体規則性、ブロック／ランダム共重合体を指定します。共重合体のnはAの個数で、Bは別に指定し、合計100単位までです。A/Bの個数を固定して配列をシャッフルするため、無限鎖のベルヌーイ配列モデルではありません。正確な配列とシードをプロジェクトに保持します。PEGはOH／OH末端の単独鎖です。手描き単位は単独鎖で使います。

アイソ／シンジオタクチックは主鎖に対する相対配置として指定します。CIPのR/Sの並びをそのまま立体規則性とはみなしません。異種A/Bの共重合体に対するアイソ／シンジオ指定は、この版では解釈の曖昧さを避けて受け付けません。乱数で指定した1本の配置は、バルクのアタクチック分布を再現するものではありません。

「繰り返し単位で表示」で括弧表示と全鎖表示を切り替えます。共重合体の省略表示はA/Bの模式図です。元の単位は「単位を編集」から開けます。手描き単位のA/B接続点は図の原子をクリックして指定できます。

### 配座、待ち行列、復旧

「配座を探索」はETKDGv3で最大30候補を作り、MMFF94またはUFFで最適化・順位付けします。構造の重複を除きますが、対称性をすべて考慮する完全な同値判定ではありません。「表示・選択」で選んだ配座は次の計算の入力になります。探索の乱数シード、原子順序、構造と座標のハッシュを保持し、構造変更後の古い配座は使いません。

候補を個別またはまとめて待ち行列へ追加し、現在の設定で順番に計算できます。待ち行列は30件まで。失敗した計算の入力とログも残ります。中断状態は再起動時に自動実行せず、「再実行待ち」から最初からやり直します。SCFの途中状態から再開する機能ではありません。通常の実行も自動で記録します。

### 電子状態と比較

「軌道・電荷」は収束したHF／DFTのHOMO/LUMOの実振幅から±等値面を生成します。28³の有限格子による表示で、定量積分や高精度な空間解像度は保証しません。開殻ではα／βを選択できます。色は軌道の位相であり、電荷ではありません。格子はGaussian Cube形式で書き出せます。

Mulliken電荷は同じ計算の電子密度を分割した値で、基底関数に依存します。「結果を比較」は計算履歴と待ち行列から結果を表示し、同一組成・電荷・多重度・計算法・基底・タスクにまとめた場合だけ相対エネルギーを表示します。エネルギー差は電子エネルギーで、熱補正・ゼロ点補正を含みません。

「レポート」は条件・バージョン・入力構造・選択配座・結果・座標・ログを単独HTMLへ保存します。ブラウザで印刷/PDF保存、またはアプリの「書き出し → 印刷 / PDF」を使えます。比較はCSV、軌道はCubeでも保存できます。
